HTML text pages, videos, quizzes, and discussion forums were intentionally skipped and are not listed.

## Category key

| Tag | Meaning |
|---|---|
| MLS | Mentored Learning Session materials (live-session slides, datasets, notebooks) |
| Lecture Notes | Slides / notes PDFs tied to weekly lecture content |
| Lecture Notebooks | Jupyter notebooks and code files tied to weekly lecture content |
| Practice Exercise | Additional/optional case-study exercises and their solutions |
| Additional Material | Supplementary datasets, references, configs, and monographs |
| Project | Main course project files (templates, datasets, solutions, rubrics, support sessions) |
| Additional Project | Secondary/bonus project files (templates, datasets, solutions) |
| Program Info | General program/orientation documents (Program Overview course only) |
